# 研究 2 的时序深度学习基线（TempCNN）：结果

判据见 `PROTOCOL.md`（预注册，SHA-256 `de5a7cd5…`）。数字来自 `site{1,2}/cells.csv` 和 `site{1,2}/judgement.json`，由 `tdl_stats.py` 计算，采用两级 bootstrap，2,000 次，seed 20261001。每个站点 16 格：2 年 × 2 轨 × M ∈ {1, 2, 4, 8}，每格用 E3 的前 3 个随机设计，与 HGB 逐格配对。

## 预注册判定

| 判据 | 站点 A | 站点 B |
|---|---|---|
| T1：BA_DL(O2) − BA_HGB(O2) | 16/16 格 > 0，范围 +1.94～+8.07 | 16/16 格 > 0，范围 +0.58～+5.34 |
| **T2**：M ≤ 2 时 ΔC_DL < ΔC_HGB，至少 6/8 格 | **3/8，不一致** | **6/8，一致** |
| T3：M = 8 时 ΔC_DL < 1 pp，4/4 格 | 3/4，未满足（2024 T37 为 +1.03 [0.12, 2.01]） | 4/4，满足 |

## 描述

| | 站点 A | 站点 B |
|---|---|---|
| 16 格平均：ΔC_DL / ΔC_HGB | +1.00 / +0.91 | +0.88 / +1.10 |
| ΔC_DL − ΔC_HGB 的范围 | −1.60～+1.58 | −0.81～+0.42 |
| 区间不含 0 的格子 | 1/16（2025 T37 M1：+1.58 [0.17, 2.94]） | 1/16（2025 T37 M4：−0.68 [−1.30, −0.09]） |

**解读**：两个站点上，时序 CNN 都比 HGB 准确。它从相干性得到的增益与 HGB 在同一量级，逐格差异大多不显著，方向在两个站点相反：T2 在站点 A 不一致，在站点 B 一致。所以，没有一致的证据表明时序建模能吸收作物分类中相干性的增益。这与研究 1 中空间上下文的结果不同：CNN 在两个站点分别只保留了 RF 增益的 31% 和 43%。
