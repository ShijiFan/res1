# 参考标签敏感性协议（2026-10-12，运行前写定）

## 动机
外部意见：Study 1 标签来自 WorldCover 2021 与 CORINE 2018（早于 2024 SAR），且只在两者一致的 C2 像元上训练和评估（Site A 287,013 / 608,825 个 Ω 像元；Site B 505,806 / 843,251）。需要量化：(i) 一致性筛选是否决定了相干性增益；(ii) 与 SAR 同年的独立登记数据是否给出同向结果。已知事实（已在稿中）：BAG 建筑登记检验在 Site A 显示孤立建筑召回下降、聚落改善。

## 设计（不训练任何模型）
- 模型：Study 1 已保存的 RF 与 SVC（I28 vs I28_G29，4 源轨 × 3 种子，各 3 个目标轨），两站点。只做推理，用 R1 原特征提取器；每个模型在已保存的样本预测上做逐行一致性核对，不一致即 STOP。
- 像元：评估块内全部 Ω 像元（Site A 160,618；Site B 255,544）。训练集与块划分不变。
- L1 标签来源敏感性（5 类 BA，与正文同一估计量：跨轨池化、种子平均、20,000 次配对块 bootstrap，RandomState(42)，所有类均出现的抽样）：
  - L1a：全部 Ω 像元，WorldCover 单独作参考；
  - L1b：全部 Ω 像元，CORINE 单独作参考；
  - L1c：仅非一致像元（Ω \ C2），WorldCover 作参考。
- L2 同期登记参考（2024）：BRP 2024 定稿地块（category Grasland → 草地；Bouwland → 耕地）在 4 m 子格栅格化，40 m 像元 100% 落在同一类地块内才算纯像元；BAG（已有 f_BAG）不参与 L2。指标：草地、耕地召回及二者均值（预测为其他三类均计为错误），差值与区间同上。L2 是描述性检验，覆盖 5 类中的 2 类。

## 判据（结果出来前写定）
- L1：若 L1a 与 L1b 下 RF、SVC 在两站点的增益区间下界均 > 0 → 正文数据节加一句“增益不依赖一致性筛选”，补充材料给全表；若任一下界 ≤ 0 → 补充材料如实报告，正文改为说明增益在一致像元上测得，并给出全像元数值。L1c 只报告，不作判据（非一致像元的参考本身有争议）。
- L2：草地/耕地均值召回增益下界 > 0 → 正文一句“同期 2024 地块登记给出同向结果”；≈0 或为负 → 补充材料报告，并在正文说明相干性增益主要来自建成区与林地的区分（与已有类别召回一致）。
- 无论结果如何，全部数值写入补充材料。
