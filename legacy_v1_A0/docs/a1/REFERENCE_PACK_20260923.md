**Defensible A1 question:** Given the same SAR acquisition endpoints, parcel cohort, split, and classifier, how does the *incremental* gain from coherence change as independent observation pairs and their processing credits increase? Does that curve reproduce across 2024/25? This is a proposed question, **not a proven novelty claim**; inspect the full Wang et al. paper and its supplement before fixing the title/abstract.

## 3. Code reading order and exact adaptation target

1. **Catalogue:** [`asf_search`](https://github.com/asfadmin/Discovery-asf_search) (BSD-3-Clause). Adapt search/query logic to emit `scene_manifest_<site>_<year>.csv`; then build `pair_manifest_<year>.csv` by validating endpoints, time lag, track/platform, coverage and baseline. Do not infer a processable burst pair from metadata alone.
2. **Processing:** [`hyp3-sdk`](https://github.com/ASFHyP3/hyp3-sdk) (BSD-3-Clause) to prepare dry-run jobs, submit only an approved batch, query completion and download with checksums. Keep job IDs and credit charges in the run ledger.
3. **Published crop baseline:** [`extended-pastis-r`](https://github.com/was-xy/extended-pastis-r) for architecture and exact feature definitions. Start by reading the paper's input construction and leave-one-region-out protocol. Its reported mIoU is **not** A1's balanced accuracy and cannot be put in one comparison column.
4. **Historical Dutch precedent:** [`Agricultural-SandboxNL`](https://github.com/ManuelHuber-Github/Agricultural-SandboxNL) (GPL-2.0). Read the data query and coherence notebook to check temporal/orbit organization; do not paste GPL code into this MIT repository.
5. **Temporal model reference:** [`pastis-benchmark`](https://github.com/VSainteuf/pastis-benchmark) (MIT). Treat PSE/TAE code as a *later* model sensitivity test; first make the matched O2/O3 parcel table and HGB/RF/LR baselines pass.
   The [2025 TGRS author repository](https://github.com/Niantangliu/Deep-learning-crop-mapping) gives an additional SAR temporal-model comparator; verify its per-file licence and dataset access before reuse.
6. **Spatial-fold idea:** [`blockCV`](https://github.com/rvalavi/blockCV) (GPL-3.0). It illustrates spatially separated folds, but A1 must implement/verify its own fixed 5 km blocks and **400 m polygon-to-test-area exclusion**; a generic `GroupKFold` call does not enforce this buffer. Do not paste GPL code into this MIT repository.

The license labels above describe the linked repositories as inspected 2026-09-23; the owner should recheck their current LICENSE and dependency terms before importing anything. This repository adds **links and analysis only**; no external PDFs, code or large datasets are vendored.

## 4. Candidate comparisons, in the right order

| Candidate | Why useful | Gate before claiming a result |
|---|---|---|
| A1 O2 vs O3, identical endpoints | Isolates coherence increment under each pair budget. | Same training/test parcel IDs, same fold, same date endpoints, classifier and hyperparameter-search budget. |
| 6-day vs 12-day pair baseline | Connects directly to 2020 JSTARS and 2022 RSE. | Same calendar support, pair count, parcel cohort; stratify platform and perpendicular baseline. |
| 2024 vs 2025 | Tests whether the shape of the budget response repeats. | Annual BRP truth, common class table, comparable day-of-year windows and matching pair design. |
| SODAS external check | Can challenge physical interpretation beyond Dutch farms. | Verify variable definitions, rain timing, temporal support and licence; report as external exploratory validation, not pooled A1 performance. |
| SandboxNL historical check | Can stress-test parcel-level temporal feature code cheaply. | Account for older years, orbit 110 coherence only, and sigma0/gamma0 processing mismatch. |
| PASTIS-R/extended PASTIS-R model | Tests whether conclusions depend on a simple tabular learner. | Only after core spatial protocol and locked predictions; compare within one dataset/metric, not paper-to-paper scores. |

## 5. Manuscript citation slots

- **Introduction / prior art:** 2020 JSTARS, 2024 ASR, 2025 TGRS, 2026 IJAEOG. State precisely that coherence crop mapping and regional shift have been studied. Then define the still-open, *matched processing-budget* question as the study target.
- **Physical rationale / E2:** 2022 RSE, 2023 Sensors, 2026 SODAS. Tie lag, precipitation and crop growth to the observable without claiming a particular field operation from coherence alone.
- **Dutch data and labels:** cite PDOK release/version for each year; cite 2022 SandboxNL for historical precedent, not as source of the 2024/25 dataset.
- **Methods:** cite ASF/HyP3 product and cost documentation with access date; identify actual processing versions, pair manifests and product hashes in the paper/supplement.
- **Discussion:** compare **questions and protocols** with Wang et al.; absolute cross-paper mIoU/BA numbers are not a controlled comparison.

## 6. Stop rules

Do not start paid bulk jobs until scene/pair manifests, live credit balance and a bounded dry-run batch are reviewable. Do not state a budget law, cross-year generality or causal farm-event explanation from a plan, code completion or a single successful pilot. Keep negative curves and failed pairs in the run record. Freeze citations only after rechecking DOI metadata against the publisher/official repository; these links are a curated reading list, not a finished manuscript bibliography.
